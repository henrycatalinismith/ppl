You'd like to contribute to the development of ppl? Great! Here's a quick introduction.

Report A Bug

This project uses Github Issues to track bug reports. The tracker is at github.com/henrycatalinismith/ppl/issues.

Get The Code

The main source repository for ppl is hosted on GitHub at github.com/henrycatalinismith/ppl.

Do Your Best

ppl is written in Rust. Build it with cargo build and run the tests with cargo test. Code should be formatted with cargo fmt and pass cargo clippy without warnings.
