ppl has been rewritten in Rust. The commands, their output and the vCard
address book format are unchanged, so existing address books and scripts keep
working as before.

The major version number changes because ppl is now installed differently.
It's published on crates.io as `ppl-cli` instead of on RubyGems, but the
command is still called `ppl`:

    $ cargo install ppl-cli

The Ruby gem is no longer maintained and won't receive further releases. If
you installed it previously, remove it with `gem uninstall ppl` before
installing the new version.

`ppl init` now sets the new address book as your default if you don't already
have one, so there's no need to edit `~/.pplconfig` by hand after creating
your first address book.
